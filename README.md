# 星域游戏平台 · GalaxyPlay

一个完全原创的网页游戏平台（应用感界面，可在浏览器/平板直接游玩）。

## 功能
- 启动画面 + 特效
- Steam 风格主界面（商店 / 我的库 / 社区 / 个人资料）
- 邮箱登录 + 验证码 + 自动注册 + 自动识别已注册邮箱
- 多款原创高画质游戏（射击《星火防线》、跑酷《极速狂飙》、剧情冒险《星际拾荒者》、养成《星域农场》）
- 玩家创意工坊：玩家可上架自己的游戏，管理员审核通过后全平台可见
- 社区评测、平台动态、成就系统、经验升级、愿望单、好友、游戏库
- 数据保存在本地（localStorage），支持 Ctrl+S / Cmd+S 导出备份 JSON 上传到 GitHub 保留

## 部署（GitHub Actions 云打包）
仓库已包含 `.github/workflows/deploy.yml`。推送到 main 分支后，GitHub 会自动构建并发布到 GitHub Pages。

步骤：
1. 新建一个 GitHub 仓库（例如 `galaxy-play`），把本目录所有文件推送上去。
2. 仓库 Settings → Pages → 部署来源选择 "GitHub Actions"。
3. 首次推送会自动触发构建，稍等 1~2 分钟即可通过链接访问。
